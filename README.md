# 考研学习助手

一个面向 iPad 的 PWA 学习应用，帮助管理考研学习计划、刷题、整理笔记和追踪进度。

## 功能特性

### 1. 仪表盘
- 考研倒计时（2026年12月26日）
- 今日任务概览
- 各科进度环形图
- 连续学习天数统计

### 2. 学习计划
- 日历视图查看整月安排
- 创建/编辑/删除学习任务
- 滑动标记任务完成
- 按科目筛选任务

### 3. 刷题练习
- 选择科目 → 选择章节 → 开始练习
- 选择题答题界面（A/B/C/D）
- 提交后显示正确答案和解析
- 答错的题目自动进入错题本

### 4. 错题本
- 按科目筛选错题
- 间隔重复复习提醒
- 统计面板：总错题数、已掌握数、待复习数

### 5. 知识框架
- 树形结构展示四科知识体系
- 标记掌握程度（0%-100%）
- 关联笔记内容

### 6. 笔记
- Markdown 格式笔记编辑器
- 实时预览渲染效果
- 搜索笔记内容

## 技术栈

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS** - 深色主题（Obsidian 风格）
- **Zustand** - 状态管理，数据持久化到 localStorage
- **Framer Motion** - 页面过渡动画
- **Lucide React** - 图标库
- **next-pwa** - PWA 离线支持

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

## 项目结构

```
src/
├── app/                    # 页面路由
│   ├── page.tsx           # 仪表盘
│   ├── plan/              # 学习计划
│   ├── practice/          # 刷题练习
│   ├── mistakes/          # 错题本
│   ├── knowledge/         # 知识框架
│   └── notes/             # 笔记
├── components/            # 组件
│   ├── layout/            # 布局组件
│   └── ui/                # UI 组件
├── hooks/                 # 自定义 Hooks
├── lib/                   # 工具函数和示例数据
├── store/                 # Zustand 状态管理
└── types/                 # TypeScript 类型定义
```

## 数据存储

所有数据存储在浏览器的 localStorage 中，包括：
- 学习任务
- 题目和错题记录
- 知识框架和掌握程度
- 笔记内容
- 学习连续天数

## 部署

### Vercel 部署
1. 将项目推送到 GitHub
2. 在 Vercel 中导入项目
3. 一键部署

### iPad 使用
1. 用 Safari 打开部署后的网址
2. 点击分享按钮 → "添加到主屏幕"
3. 桌面出现应用图标，全屏使用
4. 支持离线使用

## 间隔重复算法

错题复习间隔：
- 第 1 次答对 → 3 天后复习
- 第 2 次答对 → 7 天后复习
- 第 3 次答对 → 15 天后复习
- 第 4 次答对 → 标记为已掌握
